# Требования к внешним интеграциям для сервисов «Умный дом»

## 1. Требования к безопасности
- Шифрование всех каналов связи (TLS 1.2 или выше).
- Взаимная аутентификация между системами
- Минимизация хранимых персональных данных во внешней платформе — данные пользователей остаются в системе PropDevelopment.
- Логирование всех обращений к сервисам «Умный дом» с последующим контролем доступа к логам.
- Защита от атак на уровне API (rate limiting, защита от brute force).
- Соответствие законам о защите персональных данных.

## 2. Протоколы аутентификации и авторизации
- OAuth 2.0 + OpenID + MFA.

## 3. Организация взаимодействия систем
- Обмен данными:
  - Запросы от мобильного приложения → Backend PropDevelopment → API партнёра «Умный дом».
  - Ответы от партнёрских сервисов возвращаются через Backend PropDevelopment.
- Обработка биометрии и номеров автомобилей:
  - Распознавание выполняется на стороне платформы партнёра.
  - В PropDevelopment сохраняются только события (лог: кто и когда получил доступ).
- Мониторинг и аудит:
  - SIEM получает события об обращении к сервисам партнёра.
  - Инциденты безопасности автоматически эскалируются в SOC.
