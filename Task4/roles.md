| Роль            | Права роли                                                                                   | Группы пользователей          |
| --------------- | -------------------------------------------------------------------------------------------- | ----------------------------- |
| viewer        | Просмотр ресурсов (pods, deployments, services, configmaps – только read-only) | Аналитики                     |
| operator      | Управление ресурсами (создание/обновление/deploy приложений, но без доступа к секретам)      | DevOps инженеры, поддержка |
| admin         | Полный доступ ко всем ресурсам, включая секреты                                              | Администраторы, служба безопасности   |
